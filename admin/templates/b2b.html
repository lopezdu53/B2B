📊 Incrustar el mapa en PowerPoint

Copia este enlace y pégalo en el complemento Web Viewer de PowerPoint. Muestra el mapa interactivo (con filtros, colores y datos del negocio), en modo solo lectura.

  1. En PowerPoint: pestaña Insertar → Obtener complementos (o Mis complementos).
  2. Busca e instala “Web Viewer” (de Microsoft) y añádelo a la diapositiva.
  3. Pega el enlace copiado y presiona Preview / Vista previa.
  4. Ajusta el tamaño del recuadro en la diapositiva. Al presentar, el mapa es interactivo.
🔒 El enlace es privado y de solo lectura: muestra el mapa pero no permite editar ni ver el CRM. El complemento Web Viewer requiere que tu plataforma esté publicada con HTTPS. Si compartes el enlace, cualquiera con él podrá ver este mapa.
